# Learning Identity Management

## IAM Foundations & Identity Lifecycle
CISSP Domain: Domain 5 - Identity and Access Management (IAM)

### Learning Objectives:
	•	Understand core IAM concepts and terminology
	•	Learn the identity lifecycle management process
	•	Explore different identity types (human, service, device)

### Study Topics:
	•	Identity vs. Authentication vs. Authorization
	•	Identity lifecycle (provisioning, maintenance, deprovisioning)
	•	Identity governance principles
	•	Digital identity fundamentals
  
### Assignment:

Create a comprehensive IAM glossary (50+ terms) and design an identity lifecycle flowchart for a fictional organization with 500+ employees. Include onboarding, role changes, and offboarding processes.
